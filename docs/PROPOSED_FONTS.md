## 🔍 جزئیات فنی و نحوه پیاده‌سازی در PR آینده

### ۱. فونت‌های موجود در سرور Google Fonts (بالو و مرحی)
این دو فونت مستقیماً روی سرورهای گوگل فونتز قرار دارند و نیازی به قرار دادن فایل سنگین محلی در مخزن ندارند:
```javascript
// اضافه شدن به src/fonts.js
{
  id: 'baloobhaijaan2',
  label: 'بالو (Baloo)',
  family: "'Baloo Bhaijaan 2', cursive",
  rtl: true,
  lang: 'fa',
  google: 'Baloo+Bhaijaan+2:wght@400;700;800',
  license: 'OFL-1.1',
  creator: 'Ek Type'
},
{
  id: 'marhey',
  label: 'مرحی (Marhey)',
  family: "'Marhey', cursive",
  rtl: true,
  lang: 'fa',
  google: 'Marhey:wght@400;700',
  license: 'OFL-1.1',
  creator: 'Nasrullah Type'
}
```

### ۲. فونت‌های محلی سبک صابر راستی‌کردار و امید امامیه (صمیم، تنها، شبنم، گندم، دیروز)
این فونت‌ها به صورت فایل‌های سبک و بهینه‌شده `woff2` در مسیر `public/fonts/` قرار گرفته و در `src/index.css` تعریف خواهند شد:
```css
@font-face {
  font-family: 'Samim';
  src: url('/fonts/Samim.woff2') format('woff2');
  font-weight: normal;
  font-display: swap;
}
@font-face {
  font-family: 'Dirooz';
  src: url('/fonts/Dirooz.woff2') format('woff2');
  font-weight: normal;
  font-display: swap;
}
```

## 🎯 فازبندی ارسال در Pull Request بعدی
1. دانلود نسخه‌های بهینه (Woff2) فونت‌های صمیم، تنها، شبنم، گندم و دیروز از مخازن گیت‌هاب رسمی سازندگان.
2. افزودن تعاریف CSS در `index.css` و متادیتا در `src/fonts.js`.
3. تست رندرینگ حروف و کشیدگی (تطویل) در بوم ادیتور.
4. ایجاد شاخه تمیز `feat/persian-creative-story-fonts` و ارسال PR مستقل به `FontWoW/FontWoW.github.io`.
